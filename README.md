# Data Pipeline Sandbox

A simple Node.js sandbox environment for testing GitHub Actions CI/CD workflows, data transformation, and cron pipelines.

## Purpose

This repository is purely for learning and testing continuous integration strategies. It processes dummy datasets to test rate-limiting algorithms, asynchronous delays, and file I/O operations in a serverless environment.

## Usage

Do not fork or use in production. This is an experimental sandbox. 
All workflows and scripts are strictly for CI/CD demonstration purposes.

```bash
npm install
npm test
```

## Features Tested
- GitHub Actions concurrency controls
- Automated PR creation and merging
- Node.js native test runner
- File system persistence strategies
